# MVP Scope — SuitRent SaaS

## نظرة عامة

| البند | التفاصيل |
|---|---|
| **المدة** | 3–4 أسابيع |
| **الميزانية** | <$30/شهر |
| **المحلات** | محل تجريبي واحد عند الإطلاق؛ مع لوحة مركزية لمسؤول النظام لإدارة المحلات والاشتراكات |
| **المنصات** | تيليجرام بوت + لوحة تحكم ويب |
| **قاعدة البيانات** | PostgreSQL |

---

## الأسبوع 1: الأساسيات (Foundation)

- [ ] تثبيت Laravel + Filament + stancl/tenancy
- [ ] إعداد PostgreSQL بدلاً من SQLite
- [ ] إعداد Docker Compose (Nginx + Laravel + n8n + PostgreSQL)
- [ ] إعداد المتغيرات البيئية لـ Laravel (.env) ولـ n8n على الـ VPS (GROQ_API_KEY, OPENAI_API_KEY, TELEGRAM_BOT_TOKEN)

### قاعدة البيانات
- [ ] إنشاء migration لجدول `tenants`
- [ ] إنشاء migration لجدول `users` (مع tenant_id, role, telegram_user_id)
- [ ] إنشاء migration لجدول `items` (مع JSONB custom_fields)
- [ ] إنشاء migration لجدول `bookings` (مع كل الحقول المالية)
- [ ] إنشاء migration لجدول `booking_items`
- [ ] إنشاء migration لجدول `booking_payments` (سجل حركات الدفع والغرامات)
- [ ] إنشاء migration لجدول `collateral_records`
- [ ] إنشاء migration لجدول `item_maintenance`
- [ ] إنشاء migration لجدول `audit_logs`
- [ ] إنشاء Global Scope لكل النماذج (tenant_id scoping)

### المصادقة والصلاحيات
- [ ] تسجيل دخول لوحة التحكم (email/password)
- [ ] نظام أدوار للمحل: owner / staff، مع دور منفصل لمسؤول النظام (System Admin)
- [ ] حماية كل الصفحات حسب الدور
- [ ] قائمة بيضاء لتيليجرام (جدول + CRUD في لوحة التحكم)
- [ ] لوحة مركزية لمسؤول النظام لإدارة المحلات وسجلات الاشتراك
- [ ] تسجيل رسوم شهرية ثابتة لكل محل (المبلغ يُحدد لاحقاً؛ التحصيل يدوي بلا بوابة دفع)
- [ ] تحديد tenant للويب من حساب المستخدم الموثّق، ولتيليجرام من سجل القائمة البيضاء قبل معالجة الطلب

---

## الأسبوع 2: المخزون والحجوزات (Inventory & Bookings)

### إدارة المخزون
- [ ] نموذج Item مع الحقول: name, category, size, color, status, custom_fields (JSONB)
- [ ] صفحات Filament: قائمة، إضافة، تعديل، حذف
- [ ] تصنيفات: suit, shirt, shoes, belt, tie, vest, lapel_pin
- [ ] حالات العنصر: available, booked, cleaning, maintenance, retired
- [ ] دعم الحقول المخصصة لكل محل (Dynamic Fields)

### الحجز اليدوي (لوحة التحكم)
- [ ] نموذج حجز جديد: بيانات العميل + العناصر + التواريخ + المبالغ
- [ ] اختيار عناصر متعددة (dynamic bundle)
- [ ] حساب الإجمالي تلقائياً (base + alterations + accessories)
- [ ] تسجيل الدفعة المقدمة وطريقة الدفع
- [ ] تسجيل بطاقة الهوية (حالة held فقط — لا صور)
- [ ] قفل العناصر في التواريخ المحددة (SELECT FOR UPDATE)
- [ ] منع الحجز إذا العنصر غير متوفر

### فحص التوفر
- [ ] API endpoint: POST /api/v1/availability/check
- [ ] التحقق من تداخل التواريخ مع الحجوزات الحالية
- [ ] التحقق من فترة التنظيف (buffer)
- [ ] إرجاع حالة كل عنصر: متاح / محجوز / قيد التنظيف

---

## الأسبوع 3: تيليجرام بوت + الإرجاع (Bot + Returns)

### تيليجرام بوت (n8n)
- [ ] إعداد webhook في n8n
- [ ] استقبال الرسائل الصوتية
- [ ] التحقق من القائمة البيضاء (user_id)
- [ ] تحويل الصوت إلى نص (Groq Whisper)
- [ ] استخراج البيانات (GPT-4o-mini مع json_schema)
- [ ] إرسال بطاقة ملخصة مع أزرار [Confirm & Save] / [Edit / Cancel]
- [ ] عند التأكيد: إرسال البيانات إلى Laravel API
- [ ] عند التعديل: طلب التصحيح من المستخدم
- [ ] معالجة البيانات الناقصة (طلب الناقص من المستخدم)

### معالجة الإرجاع
- [ ] صفحة إرجاع في لوحة التحكم
- [ ] عرض قائمة العناصر المحجوزة
- [ ] تحديد حالة كل عنصر: سليم / تالف / مفقود
- [ ] حساب الغرامة للعناصر التالفة/المفقودة
- [ ] إرجاع بطاقة الهوية (فقط إذا لا توجد غرامات معلقة)
- [ ] تحصيل المتبقي من الإيجار
- [ ] إدخال العنصر في حالة التنظيف تلقائياً
- [ ] تسجيل كل شيء في سجل التدقيق

### فترة التنظيف (Buffer)
- [ ] عند الإرجاع: إدخال العنصر في حالة cleaning
- [ ] حساب تاريخ الجاهزية (buffer_hours من إعدادات المحل)
- [ ] منع حجز العنصر قبل انتهاء الفترة
- [ ] مهمة مجدولة (Laravel Scheduler) لتحويل العنصر إلى available
- [ ] إمكانية تمديد الفترة يدوياً (صيانة)

## الأسبوع 4: التقارير + الاختبار + النشر (Reports + Testing + Deployment)

### التقارير المالية
- [ ] تقرير يومي: إجمالي الحجوزات، الإيرادات، المستحقات
- [ ] تقرير أسبوعي/شهري
- [ ] فلترة حسب التاريخ
- [ ] عرض طرق الدفع المختلفة
- [ ] عرض الغرامات المحصلة

### سجل التدقيق
- [ ] صفحة عرض سجل التدقيق في لوحة التحكم
- [ ] فلترة حسب: المستخدم، العملية، التاريخ
- [ ] تسجيل تلقائي لكل العمليات الحساسة

### لوحة التحكم
- [ ] صفحة رئيسية (Dashboard) مع ملخص:
  - حجوزات اليوم
  - عناصر قيد التنظيف
  - مستحقات معلقة
  - إجمالي الإيرادات (الشهر)
- [ ] تقويم الحجوزات
- [ ] إدارة المستخدمين (إضافة/تعديل/تعطيل)
- [ ] إعدادات المحل (buffer hours, pricing rules)

### الاختبار
- [ ] اختبار الحجز اليدوي
- [ ] اختبار الحجز الصوتي (تيليجرام)
- [ ] اختبار الإرجاع (سليم + تالف + مفقود)
- [ ] اختبار فترة التنظيف
- [ ] اختبار الصلاحيات (owner vs staff)
- [ ] اختبار القائمة البيضاء
- [ ] اختبار منع الحجز المزدوج (concurrent bookings)
- [ ] اختبار الأداء (< 5 ثوانٍ للبوت)

### النشر
- [ ] إعداد VPS (Hetzner/DigitalOcean)
- [ ] تثبيت Docker + Docker Compose
- [ ] نشر Laravel + PostgreSQL + n8n
- [ ] إعداد Nginx + SSL (Let's Encrypt)
- [ ] إعداد النسخ الاحتياطي اليومي
- [ ] مراقبة الأداء والأخطاء

## ملخص المهام حسب الأولوية

### P0 (يجب يعمل في الـ MVP)
- [ ] بنية multi-tenancy كاملة
- [ ] لوحة مسؤول النظام لإدارة المحلات والاشتراكات مركزياً
- [ ] ربط tenant بمستخدم الويب الموثّق وبمستخدم تيليجرام المصرح له
- [ ] تسجيل دخول (بريد وكلمة مرور) + أدوار
- [ ] إدارة المخزون (CRUD)
- [ ] حجز يدوي (لوحة التحكم)
- [ ] حجز صوتي (تيليجرام)
- [ ] فحص التوفر + منع الحجز المزدوج
- [ ] معالجة الإرجاع + الفحص
- [ ] إدارة بطاقة الهوية (held/released)
- [ ] فترة التنظيف التلقائية
- [ ] سجل التدقيق
- [ ] القائمة البيضاء لتيليجرام

### P1 (مهم لكن يمكن تأجيله أسبوع)
- [ ] التقارير المالية المتقدمة
- [ ] تقويم الحجوزات
- [ ] لوحة رئيسية مع ملخص
- [ ] إدارة المستخدمين المتقدمة

### P2 (بعد الـ MVP)
- [ ] دعم التحقق بخطوتين (2FA / TOTP)
- [ ] تطبيق جوال
- [ ] إشعارات للعملاء
- [ ] تكامل بوابات الدفع
- [ ] تقارير بالرسوم البيانية
- [ ] تصدير Excel

## الـ APIs المطلوبة

| Method | Endpoint | الوصف |
|---|---|---|
| POST | `/api/v1/availability/check` | فحص توفر العناصر |
| POST | `/api/v1/bookings` | إنشاء حجز |
| GET | `/api/v1/bookings` | قائمة الحجوزات |
| GET | `/api/v1/bookings/today` | حجوزات اليوم |
| POST | `/api/v1/bookings/{id}/return` | معالجة الإرجاع |
| POST | `/api/v1/bookings/{id}/collateral/release` | إرجاع بطاقة الهوية |
| GET | `/api/v1/items` | قائمة المخزون |
| POST | `/api/v1/items` | إضافة عنصر |
| GET | `/api/v1/reports/financial` | التقارير المالية |
| GET | `/api/v1/audit-logs` | سجل التدقيق |

## معايير القبول النهائية

| المعيار | الهدف |
|---|---|
| استجابة البوت | < 5 ثوانٍ (صوت → بطاقة تأكيد) |
| الحجوزات المزدوجة | صفر (منع 100%) |
| وقت التشغيل (Uptime) | 99%+ خلال ساعات الذروة |
| عزل البيانات | 100% (لا تسريب بين المحلات) |
| التكلفة الشهرية | < $30 |

## ما خارج نطاق الـ MVP

- ❌ تطبيق جوال (iOS/Android)
- ❌ بوابة دفع (PalPay/Jawwal Pay API)
- ❌ تسجيل عميل ذاتي
- ❌ إشعارات SMS/WhatsApp للعملاء
- ❌ تقارير متقدمة (رسوم بيانية)
- ❌ دعم لغات إنجليزية
- ❌ تسعير اشتراكات متعدد المستويات
- ❌ تكامل مع أنظمة محاسبة خارجية
