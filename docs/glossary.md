# Glossary — SuitRent SaaS

## مصطلحات المشروع

### الكيانات الأساسية

| المصطلح | التعريف |
|---|---|
| **Tenant** | محل تأجير بدلات مستقل يستخدم النظام (SaaS multi-tenant) |
| **Item** | قطعة ملابس أو إكسسوار قابلة للتأجير (بدلة، قميص، حذاء، حزام، ربطة عنق...) |
| **Booking** | حجز عميل لمجموعة عناصر لفترة زمنية محددة |
| **BookingItem** | عنصر مرتبط بحجز معين (dynamic bundle) |
| **Collateral** | بطاقة الهوية الوطنية التي يحجزها المحل كضمان |
| **Buffer / Turnaround** | فترة التنظيف والصيانة بين حجزين (24–48 ساعة) |
| **Alteration** | تعديل على مقاس البدلة (قص، تطريز...) يؤثر على السعر |
| **Deposit / Advance** | دفعة مسبقة من إجمالي الإيجار (ليست ضماناً مسترداً) |
| **Penalty** | غرامة تُفرض عند تلف أو فقدان عنصر |

### الأدوار

| الدور | الصلاحيات |
|---|---|
| **Owner** | صلاحيات كاملة: المخزون، التقارير المالية، إدارة الموظفين، إعدادات النظام |
| **Staff** | إنشاء حجوزات، عرض التوفر، معالجة المرتجعات، عرض الجدول اليومي |

### حالات العناصر

| الحالة | المعنى |
|---|---|
| **Available** | متاح للحجز |
| **Booked** | محجوز حالياً |
| **Cleaning / Maintenance** | قيد التنظيف/الصيانة (buffer) |
| **Ready** | جاهز للحجز بعد انتهاء الـ buffer |
| **Retired** | خارج الخدمة نهائياً |

### حالات الحجز

| الحالة | المعنى |
|---|---|
| **Active** | حجز ساري (العميل لم يسترجع بعد) |
| **Completed** | مكتمل (تم إرجاع كل العناصر وتحصيل المبالغ) |
| **Overdue** | متأخر (تجاوز تاريخ الإرجاع المتوقع) |
| **Damage Pending** | بانتظار تسوية غرامة تلف/فقدان |
| **Cancelled** | ملغي |

### حالات الضمان (Collateral)

| الحالة | المعنى |
|---|---|
| **Held** | بطاقة الهوية محجوزة لدى المحل |
| **Released** | تم إرجاع البطاقة للعميل |

### المصطلحات التقنية

| المصطلح | التعريف |
|---|---|
| **n8n** | منصة أتمتة ذاتية الاستضافة تدير webhook الخاص بـ Telegram و pipeline الذكاء الاصطناعي |
| **Groq Whisper** | نموذج تحويل صوت إلى نص (STT) يستخدم للصوت العربي |
| **GPT-4o-mini** | نموذج LLM لاستخراج البيانات المهيكلة من النص العربي |
| **Filament** | لوحة تحكم Laravel تدعم العربية/RTL |
| **Fortify** | حزمة مصادقة Laravel (يدعم 2FA) |
| **stancl/tenancy** | حزمة multi-tenancy لـ Laravel |
| **Row-level locking** | `SELECT ... FOR UPDATE` لمنع الحجوزات المتزامنة المتعارضة |
| **JSONB** | نوع بيانات PostgreSQL لتخزين الحقول الديناميكية (الإكسسوارات) |
| **RTL** | اتجاه واجهة من اليمين لليسار (العربية) |
