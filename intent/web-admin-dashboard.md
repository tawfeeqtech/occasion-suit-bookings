# Intent: Web Admin Dashboard

## Status: approved

## Author: Shop Owner

## Date: 2026-10-01

---

## What problem does this solve؟

أحتاج لوحة تحكم عربية (RTL) لإدارة المحل: المخزون، الموظفين، التقارير المالية، الإعدادات، وسجل التدقيق. بدونها أضطر للاعتماد على المطور لكل تغيير.

## Who is affected؟

- **Shop Owner**: يدير كل شيء من لوحة التحكم
- **Staff**: يمكنهم عرض الجدول اليومي فقط

## What should happen؟

1. تسجيل الدخول بالبريد وكلمة المرور (تأجيل 2FA لما بعد MVP)
2. لوحة تحكم عربية RTL بتصميم متجاوب
3. إدارة المخزون: إضافة/تعديل/حذف العناصر مع حقول مخصصة
4. إدارة الموظفين: إضافة/تعديل/تفعيل/تعطيل مع تعيين الأدوار
5. عرض الحجوزات: قائمة مع فلاتر التاريخ ضمن MVP؛ التقويم التفاعلي مؤجل لما بعد MVP (P1)
6. التقارير المالية: الإيرادات، المستحقات، الغرامات
7. إعدادات المحل: فترة التنظيف، قواعد التسعير، القائمة البيضاء لتيليجرام
8. سجل التدقيق: كل عملية مسجلة مع اسم المستخدم والوقت
9. واجهة ويب متجاوبة تعمل على الهاتف والكمبيوتر؛ لا يُبنى تطبيق جوال مستقل ضمن MVP
10. تقارير أساسية ضمن MVP؛ الرسوم البيانية وتصدير Excel مؤجلان لما بعد MVP

## What should NOT happen؟

- لا يرى الموظف التقارير المالية أو إعدادات المحل
- لا تظهر واجهة باللغة الإنجليزية في الاستخدام اليومي
- لا تضيع البيانات عند تعديل الإعدادات

## How will we know it works؟

- المالك يستطيع إدارة المحل بالكامل بدون مطور
- الواجهة تعمل على الهاتف والكمبيوتر
- كل عملية محفوظة في سجل التدقيق
